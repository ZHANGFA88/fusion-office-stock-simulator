# 全球指数定投赛跑 · 模块说明

六大指数（纳指100 / 标普500 / 沪深300 / 日经225 / 德国DAX / 法国CAC40）2010—2026
月度定投回测动画：开场地球 → 回测规则 → 最优配比 → PART I 六线单投赛跑（含 9 张事件卡）
→ PART II 组合 vs 六等分 → 终局统计 → 金句收束。全片约 117.5 秒，带播放/暂停/进度拖动/重播。

## 文件

| 路径 | 说明 |
|---|---|
| `index.html` | 单页动画站。原生 JS + Canvas/DOM，**不引外部 CDN**，离线可跑；`fetch('./data/engine.json')` 读数据 |
| `data/engine.json` | 日线引擎输出（4,380 个统一交易日、202 期、每月 ¥3,000、累计 ¥606,000） |
| `tools/` | 数据刷新工具链：`engine.py`（重算引擎）、`fetch_daily.py`（抓日线）、`build_tr.py`（构建全收益）、`fix_n225.py`（日经 1346.T 分红修正） |

## 规格与口径

- 动画规格：`~/workspace/global_etf_race/FRAME_SPEC_V3.md`（逐帧时序/动效/构图权威）＋ `FRAME_SPEC_V2.md`（文案权威）。
- **页面展示的数字一律取引擎，不硬凑视频印刷值**（结论见 `VERIFICATION.md`）：
  组合 ¥2,746,664 / +353.24%、IRR 16.17%、最大回撤 −28.0%（2020-03-23）、
  六等分 ¥1,929,073 / +218.33%、单投 纳指 +574.9 / 标普 +304.1 / 日经 +189.5 / DAX +101.0 / CAC +90.5 / 沪深 +49.9。
- 事件卡「高→低」= 窗内定投收益率最高 → 最低（非起止值），取自 `engine.json` 的 `pairs_minmax`。
- 与视频印刷值已知差异（引擎口径所致，非 bug）：纳指 +100% 里程碑按引擎为 2017（视频 2018.02）；
  事件卡主角指数窗内涨跌取引擎 `hero_idx_change`（如欧债 CAC −38.0%、新冠 DAX −26.9%）；
  PART I 慢段约 2.8 期/秒、安静段约 6.9 期/秒（规格写「窗内约 1 期/秒」，按 46 秒总时长反推不可行，已按比例折中）；
  日经 1989 高点 / 60000 点两横幅按真实历史日期（2024-02-22 / 2026-01-06）定位（引擎价格序列为 ETF 价，无指数点位）。
- 片尾数据来源小字按引擎真实来源书写（日经用 1346.T 收盘＋分红自建，Yahoo 1321.T 复权价有坏数据未采用）。

## 数据刷新

```bash
cd tools
python3 fetch_daily.py   # 抓取最新日线
python3 fix_n225.py      # 日经分红修正（如需）
python3 build_tr.py      # 构建全收益序列
python3 engine.py        # 重算 data/engine.json（输出到本模块 data/）
```

跑完把新生成的 `engine.json` 放到 `data/` 下覆盖即可，页面下次加载自动使用；口径变化时同步更新上节数字。

## 独立运行

```bash
cd /path/to/fusion-dashboard
python3 -m http.server 8770
# 打开 http://localhost:8770/modules/race/
```

注意：必须用 HTTP 服务打开，直接双击文件会因 `fetch` 同源限制读不到数据。
门户页的赛跑卡片（P1 接入后）指向本目录。
