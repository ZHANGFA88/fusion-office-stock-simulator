# AI Safety HOT 公开站点逆向记录（REA）

记录日期：2026-10-17。分析目标为 [AI Safety HOT 中文总览](https://aisafetyhot.com/zh) 与 [热点页](https://aisafetyhot.com/zh/hot)。这里只记录公开页面与请求摘要，不保存原始浏览器 Evidence、文章正文、签名查询参数或个人信息。

## 页面与数据形态

`/zh` 是一个科研观测台首页：页面把材料扫描、话题星图、新闻流和热点观察串成四个阅读阶段；还能按来源与话题浏览，并展示单条材料的时间窗口。页面文案说明，话题数字是累计公开卡片数，同一事件的报道会合并计数；连线基于最近最多 2,000 条材料的共同话题。页面声明约每两分钟检查数据，话题统计可能延迟约十分钟。

`/zh/hot` 是热点排序页，标注近 72 小时的榜单，展示热点卡片、来源和讨论链接、最新进展及时间走势。页面写明排序综合内容价值与传播度，各占 50%；账号帖子的点赞按对数加权，约 100 个赞相当于 3 倍，评论不计入该项。这是站点页面自述的算法说明，不代表我们独立验证了其生产排序逻辑。

## 蛛网结构与本次快照

总览页的数据接口返回 `topics`、`pairs`、`stats` 等字段。清洗后的话题节点具有 slug、名称、分类和累计量；分类包括机构（`company`）、研究领域（`field`）与议题类型（`genre`）。`pairs` 是带权关联边，表示材料中的话题共现。节点累计量与近期共现边的时间口径不同，不能把节点数字解释成最近 72 小时数量，也不能把连线权重解释成因果关系。

REA 6.5.0 在 2026-10-16 17:33 UTC 对 `/zh` 和 `/zh/hot` 做了一次手动捕获。有效的 `/api/site/monitor` 响应包含 50 个话题节点与 300 条带权边，分类分别为 24 个机构、17 个研究领域、9 个议题类型；站点计数为 1,273 个来源、13,021 条材料、当日 472 条。总览页在同一时段显示的材料与来源口径和热点榜单的 72 小时计数并不相同，页面也会持续更新，因此这些数值是带时间戳的样本，不是固定常量。

工作台的 Canvas 图按分类着色、按节点累计量调整大小、按边权绘制连线，并对高频节点显示标签；布局用固定锚点加确定性分布近似重绘，机构节点参考相邻节点位置排布。这是工作台中的可读性优先近似图，不是对原站布局算法或像素外观的复刻。

## 主要接口

以下将运行时证据与 bundle 静态线索分开。路径中的查询值均省略或脱敏。

**运行时确实观察到的请求：**`GET /api/site/monitor?lang=zh` 为总览页请求话题、共现边和监控计数，本次取得有效 JSON；`GET /api/site/overview?lang=zh` 为总览摘要，返回 HTTP 200；热点页的 `GET /api/site/live` 读取实时计数器，返回 HTTP 200。两页还请求 `GET /api/img-proxy?...` 加载来源图片，捕获记录中的查询值已脱敏，不公开签名或来源 URL。实际观察到页面运行时向 `POST /cdn-cgi/rum` 发送遥测，请求返回 HTTP 204；两页各另有一个站外请求，这些请求由页面脚本发起，并非工作台主动调用。

本次捕获记录了总览页 70 条、热点页 37 条首方请求，其中各有一条非 GET 请求。总数包括静态资源和图片代理，不能与业务接口数量混为一谈。

**只从公开页面资源的静态线索整理，未由本次扫描主动调用：**`GET /api/site/monitor/feed?cursor=…` 用于监控材料分页，`GET /api/site/overview/sources?lang=zh` 提供来源目录；`GET /api/site/pool/today?lang=zh` 与 `GET /api/site/pool?...` 对应今日材料池计数及筛选/分页。`POST /api/site/search/query` 与 `GET /api/site/search/query/{jobId}` 对应搜索任务提交和状态轮询，前者可能启动任务，因此没有调用。另有 `GET /api/site/stories/{id}`、`GET /api/site/timeline?...` 与 `GET /api/site/groups/{id}/…`，分别对应事件详情、时间线、来源分组或引用内容。

这些静态线索会随前端版本变化，不能据此承诺所有路由当前可用、无需参数或对匿名用户开放。未对搜索任务、写入操作、账号权限、服务端 CORS 或后台管理端点做探测。

## 接入边界与已知问题

REA 面板只扫描代码中固定的 `/zh` 与 `/zh/hot`，不接受用户提交的 URL；必须显式以 `--with-rea-inspector` 启用，并由用户手动触发。API 只接受 loopback 同源请求，扫描路由拒绝请求体，不开放通配 CORS。

REA 浏览器场景没有网络请求拦截或域名白名单。页面自行加载的资源、站外请求和 RUM 仍会发生；本功能不保证 GET-only，也不适合作为无人值守、网络隔离的扫描器。上文记录的 POST 是本次实际捕获到的证据。

原始 Evidence 与响应文章正文只在扫描进程内存中用于提取；报告只保留净化后的图谱、首方路径和站点计数，并写入静态网站根目录之外的本机数据目录（目录 0700、报告 0600）。签名查询值、原始文章标题和正文不进入 Git。图谱数据有时间延迟，页面计数口径不一；公开报告须标明采集时点，不能把样本数字当作实时保证或投资/安全结论。
