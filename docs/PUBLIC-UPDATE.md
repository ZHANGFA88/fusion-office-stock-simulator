# 公开代码更新

本次更新发布可复用代码与离线回归测试，不同步任何私有部署或运行数据。

## 已包含

- 主要页面共享“返回顶部”按钮，支持中英文、键盘操作、安全区域和减少动画偏好。
- 行情规范化记录显式区分 `LIVE` 与 `DEMO`，缺失模式不自动推断为实盘数据。
- SEC 适配器按申报日期排序并限制记录数量，保留申报元数据，仅生成申报索引链接，不抓取正文或附件。
- RSS/Atom 解析器提供默认关闭的短摘要与 HTML 命名实体兼容选项；继续拒绝 DTD/实体声明。
- 独立、无 I/O 的 PAPER 数据准入校验模块及其纯函数测试。

- 独立 BLS、香港统计处、香港金管局和美国财政部官方数据适配器及离线测试；本次不接入公开服务路由，也不启用后台采集。

## 公开预览的边界

公开服务继续使用原有 DEMO 新闻路由和只读设置页。本次未替换公开服务端、启动脚本或 AI 运行入口；新增 PAPER 校验库尚未接入公开服务的下单路径，不能视为公开服务已具备该项防护。行情、交易和其他继承接口的原有行为与限制仍以 README 为准。

不包含私有专用界面、认证实现与认证文件、本地运行配置、数据库、联系邮箱、凭据或部署截图。现有私有服务与独立 QA 预览不因本次代码发布而重启或重新部署。
